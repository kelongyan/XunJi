# 寻迹 · 中国风历史检索站

> 在本机运行的中国历史学习检索站——以中国传统典籍装帧的视觉语言为基调，像翻一部会呼吸的纸墨史册。

寻迹是一部可以"走进去"的中国历史知识库：一条水墨长河横贯屏幕，汉、唐、宋、明、清五座卷轴沿岸排布，点击卷轴便进入那个朝代的颜色。首期精修**明朝**，现已扩至**唐朝**与**宋朝**，其余朝代陆续修典。全部内容为本地静态数据，无需联网、无需登录，打开即读。

## 创作理念

### 为什么叫"寻迹"

历史学习的门槛从来不在于找不到资料，而在于资料散落各处、读起来千篇一律。我们想做的是一种"翻史册"的体验：有纸墨的温度、有版式的章法、有出处的敬畏，也有漫步时偶然拾得一叶史册的惊喜。"寻迹"二字，既是追寻历史的踪迹，也是把每一次阅读的足迹留下来。

### 视觉：典籍装帧，一朝一色

全站视觉借鉴中国传统典籍的排印体系——暖黄宣纸底、宋体正文、楷体引文、文武双线框、版心鱼尾、朱笔圈点、竖排史料、笺谱套色装裱。配色遵循"一朝一色"：明朝朱砂、唐朝鎏金、宋朝汝窑天青——**进入一个朝代，就是进入那个朝代的颜色**。

### 3D：历史是一条河

首页是一条可以漫游的三维水墨长河：远山层叠、卷轴浮岛随波轻晃、墨点漂浮。我们相信 3D 应该服务于叙事而非炫技——拖动环视、滚轮推近、点击卷轴启程，每一点交互都在讲"历史是一条奔流不息的长河"这件事本身。夜读模式下，长河入夜，卷轴亮起灯影，像夜航的漕船。

### 内容：正史为骨，推演为翼

词条以正史为骨架撰写，史料引文一律标注出处（竖排呈现，古籍自右向左读）；页边设有"史臣曰"朱批栏。站内唯一的"非史实"内容是**时空推演**——反事实历史分叉叙事（"若土木堡无此败"），全程以朱色虚线与"推演 · 非史实"朱印醒目标注，实线为史实，虚线为推想，绝不混淆。

### 本地：一部只属于你的史册

纯前端实现，无后端、无数据库、无网络请求、无用户系统。你的足迹与钤印收藏只存在你自己的浏览器里——这是一部只属于你的史册。

## 功能一览

- **3D 时空长河** — 拖拽环视、滚轮推近、点击卷轴进入朝代；空白墨点可"点墨捞史"，捞出一叶编年残句；`H` 键进入沉浸模式，纯长河漫游
- **一朝一色** — 每个朝代专题拥有专属主题色，词条页、编年长卷随朝代染色
- **词条详情** — 典籍版式排印（竖排史料原文、史家朱批、笺谱图版装裱）、流式"史学纵横"深度解读、词条纪年时序
- **3D 器物展台** — 永乐青花瓷瓶、大典书函等程序化器物，可 360° 拖转
- **郑和针路图** — 仿《郑和航海图》的 3D 航路：金色飞线、宝船巡游、十大港口竖排地名
- **编年长卷** — 唐 / 宋 / 明三朝编年时间轴，事件词条直链
- **时空推演** — 反事实历史分叉树（土木堡、下西洋、安史之乱三卷），实线史实、虚线推演
- **朝代对读** — 双词条跨朝代合参（王安石变法 vs 一条鞭法等），附"史官合论"
- **检索** — 名称 / 别名 / 标签 / 全拼 / 拼音首字母联想直达（输入 `zjz` 即达张居正），命中词高亮
- **我的寻迹** — 足迹（最近到访）与钤印藏书阁，localStorage 本地留存
- **日读 / 夜读** — 一键切换，3D 长河同步入夜亮灯；可选盖印音效

## 技术栈

Vue 3（Composition API）· TypeScript · Vite · Tailwind CSS v4 · Three.js（自写水墨 Shader）· Pinia · Vue Router · MiniSearch · pinyin-pro

纯前端实现，构建产物为静态文件。

## 快速开始

需要 Node.js 18+ 与 pnpm。

以下命令均在仓库根目录运行。

```bash
pnpm install
pnpm dev        # 开发：http://localhost:5173
pnpm build      # 类型检查 + 生产构建
pnpm preview    # 预览生产构建
```

## 目录结构

```
├─ src/
│  ├─ pages/            # 首页 / 检索 / 词条详情 / 编年长卷 / 朝代对读
│  ├─ components/
│  │  ├─ three/         # 3D 场景（时空长河 / 针路图 / 器物展台）
│  │  ├─ ai/            # 时空推演面板
│  │  ├─ search/        # 检索联想
│  │  └─ common/        # 印章 / 页眉 / 水墨转场 / 首访引导
│  ├─ data/             # 全部历史词条（唐 / 宋 / 明）与编年数据
│  ├─ composables/      # 检索 / 打字机 / 3D 场景生命周期 / 足迹 / 音效
│  ├─ stores/           # UI 状态（日读夜读 / 沉浸 / 转场）
│  └─ style.css         # 设计 token（纸墨 / 朝代色 / 古籍版式类）
└─ public/images/       # 词条笺谱图版
```
